# 真白とP3展開予想の同点数比較

既存の独立研究workerで保存済みP3 LIVE・TRUE証拠・旧真白を照合する。新研究は固定済み観測の展示コース基準だけを別の母集団として結ぶ。

- 11/17〜12/14が前向き期間。11/16の既存保存分は接続確認であり、前向き実績へ加算しない。
- 本番P3と同じレース・同じ点数で、保存済み3分岐を全て比較する。各枝を合算した架空の購入・回収率を作らない。
- 対象艇が攻める場合と、別の外艇が攻める場合を区別する。SGとモデル世代も別集計。
- 三連単的中率・投資・払戻・返還・収支・回収率、追加的中と失った的中を保存する。見送りと全返還は不的中に変換しない。
- 勝ったという結果だけで、まくり成功・壁失敗など実際の展開を認定しない。
- 元のP3・既存LOCK・係数・モデル・買い目は変更しない。公式入力の再取得、結果後の分岐券生成、追加学習、自動採用なし。
- report.jsonは独立研究cacheだけへ保存し、canonical NIGHTには戻さない。終了後の変更分は既存方式で暗号化した研究bundleを90日保持する。
- アプリ表示は別の研究用projection。欠けた親は未照合として残す。正式feed配信をこの表示の成功待ちにしない。

既存の別研究のmutable stateが新しい正本と衝突する場合、上書き禁止のseed検証は維持したまま、この研究が必要とする検証済みの旧真白・固定観測・比較reportだけを選択して取り込む。既存DEME/WILD stateは変更せず、比較と固定観測だけを継続する。

旧専用sidecarがない場合は、検証済みの公式出走・展示入力と同じP3 LIVE保存証拠で旧定義を再照合する。これは元の旧真白の旗が保存されていた実績ではないと明記し、after-the-factフラグを捏造しない。保存済み展開packetがなければ未取得とし、結果後に分岐券を生成しない。
